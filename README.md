# Boxlet

A small self-hosted PHP CMS for people who build many small sites. Runs on ordinary shared
hosting: no shell, no Composer, no build step.

**This repository is the finished install code**, written by a release. Nothing is developed
here. Development happens in [BoxletCMS/boxlet-cms-dev](https://github.com/BoxletCMS/boxlet-cms-dev).

To install, download the ZIP from [Releases](https://github.com/BoxletCMS/Boxlet-CMS/releases),
upload its `boxlet/` directory, point the domain at `boxlet/public`, and open `/install.php`
in a browser.
